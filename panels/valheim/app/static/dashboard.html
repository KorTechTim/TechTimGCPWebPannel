SERVER CONFIGURATION

서버 설정

설정은 다음 서버 시작에 적용됩니다. 기존 월드는 같은 이름을 선택하면 이어서 사용할 수 있습니다.

기본 설정

크로스플레이는 공개 IP·참가 코드·서버 목록으로 접속합니다. 로컬 IP나 127.0.0.1로는 접속할 수 없습니다. 포트를 변경했다면 GCP 방화벽도 맞춰주세요.

월드 자동 저장·백업

게임 자체의 자동 저장·백업 설정입니다. 패널에서 만든 ZIP 백업은 별도로 보관됩니다.

WORLD FILES

월드 파일

기존 월드 가져오기

이름이 같은 .db와 .fwl 파일을 함께 선택하세요. Steam 클라우드 월드는 게임에서 로컬로 옮긴 뒤 가져와주세요.

기존 월드가 있으면 먼저 ZIP 백업을 만듭니다. 업로드 후 서버 설정에서 월드를 선택해주세요.

WORLD BACKUPS

백업과 복원

ZIP 백업에는 월드와 권한 목록이 포함됩니다. 복원 전 현재 월드를 한 번 더 백업합니다.

패널 수동 백업 · 날짜순

PLAYER ACCESS

플레이어 권한

허용 목록에 한 명이라도 등록하면 이 목록에 없는 플레이어는 접속할 수 없습니다.

SCHEDULED RESTART

예약 재시작

실행 중인 서버만 정상 종료한 뒤 다시 시작합니다. 꺼진 서버는 자동으로 켜지지 않습니다.
